# skills

Agent skills for zonicdmc.

| Skill | Path | What it does |
| --- | --- | --- |
| atelier-ui | `skills/atelier-ui/SKILL.md` | Print-room art direction for landing pages and product screens. One material, one accent, one grid. |
| ui-ux-pro-max | upstream | Design intelligence: styles, palettes, type, charts, and stack guidelines. Installed from the marketplace, not copied into this repo. |

## atelier-ui

Original skill. Inspired by the idea of installable design skills such as [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill). The text here is not a copy of that repo.

```bash
npx skills add https://github.com/zonicdmc/skills --skill atelier-ui
```

## ui-ux-pro-max

Plugin `ui-ux-pro-max@ui-ux-pro-max-skill`, version 2.15.0, MIT, from [nextlevelbuilder/ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill).

Claude Code install:

```text
/plugin marketplace add nextlevelbuilder/ui-ux-pro-max-skill
/plugin install ui-ux-pro-max@ui-ux-pro-max-skill
```

The database stays upstream. This repo only records that the plugin is in use.
