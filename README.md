# skills

Agent skills for zonicdmc.

| Skill | Path | What it does |
| --- | --- | --- |
| atelier-ui | `skills/atelier-ui/SKILL.md` | Print-room art direction for landing pages and product screens. One material, one accent, one grid. |

Inspired by the idea of installable design skills such as [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill). The text here is original, not a copy of that repo.

## Install

If your agent reads `SKILL.md` files, point it at `skills/atelier-ui/SKILL.md`, or install with the skills CLI:

```bash
npx skills add https://github.com/zonicdmc/skills --skill atelier-ui
```
